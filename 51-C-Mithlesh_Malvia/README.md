## Technologies Used

- **Language:** Standard C (ISO C99 / C11 compatible; avoids non-standard Turbo C functions like `clrscr()` or `getch()`)
- **Standard Headers:** `<stdio.h>`, `<stdlib.h>`, `<string.h>`
- **Compiler (Recommended):** GCC (MinGW-w64 on Windows / GCC on Linux) or Clang
- **Documentation:** Markdown & Mermaid diagrams
- **Version Control:** Git

## How to Compile and Run C Programs

1. **Install a C compiler** (if not already installed), such as MinGW-w64 / GCC on Windows:
   ```powershell
   winget install -e --id BrechtSanders.WinLibs.POSIX.UCRT
   ```
2. **Navigate to any program directory**, for example `Lab1/Program1`:
   ```powershell
   cd Lab1/Program1
   ```
3. **Compile `main.c` using GCC with warnings enabled:**
   ```powershell
   gcc -Wall -Wextra -std=c11 main.c -o program.exe
   ```
4. **Run the executable:**
   - Windows PowerShell:
     ```powershell
     .\program.exe
     ```
   - Linux / macOS:
     ```bash
     gcc -Wall -Wextra -std=c11 main.c -o program
     ./program
     ```

## Learning Outcomes

By completing these 20 practical programs, students gain hands-on proficiency in:

1. Decision-making (`if-else-if`, `switch-case`) and loop control statements (`for`, `break`, `continue`).
2. One-dimensional and two-dimensional arrays for searching extrema and performing matrix arithmetic.
3. Safe string handling using `<stdio.h>` (`fgets`) and `<string.h>` (`strlen`, `strcpy`, `strcat`, `strcmp`, `strcspn`).
4. Modular programming with functions, parameter passing (call by value vs. pointer-based call by reference), recursion, and controlled program termination (`exit()`).
5. Memory addressing with pointers and grouping heterogeneous data using `struct`, arrays of structures, and `union`.
