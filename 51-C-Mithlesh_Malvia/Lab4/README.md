# Lab 4: String Manipulation Using `<string.h>`

## Objectives
- Measure string length and copy strings safely using `strlen()` and `strcpy()`.
- Concatenate and compare strings lexicographically using `strcat()` and `strcmp()`.

## Programs
1. [Program 1 (Q.7)](./Program1/) — Find the length of a string and copy it into another string using standard string functions.
2. [Program 2 (Q.8)](./Program2/) — Concatenate two strings and compare two strings using standard string library functions.

## Compile & Run
```powershell
gcc -Wall -Wextra -std=c11 Program1/main.c -o Program1/program.exe
.\Program1\program.exe

gcc -Wall -Wextra -std=c11 Program2/main.c -o Program2/program.exe
.\Program2\program.exe
```
