# Lab 1: Conditional Logic and Loop Basics

## Objectives
- Understand loop-based divisibility testing and prime number logic.
- Apply multi-branch conditional logic using `if-else-if` ladders with input validation.

## Programs
1. [Program 1 (Q.1)](./Program1/) — Check whether a given number is prime or not.
2. [Program 2 (Q.2)](./Program2/) — Calculate the grade of a student based on marks using `if-else-if` statements.
