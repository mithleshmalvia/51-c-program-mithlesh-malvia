# Lab 10: Array of Structures and Unions

## Objectives
- Manage multiple structured records using an array of structures and filter records by a selection condition.
- Understand memory sharing in a `union` and safely access one union member at a time.

## Programs
1. [Program 1 (Q.19)](./Program1/) — Store details of 5 employees using an array of structures and display employees matching a documented condition.
2. [Program 2 (Q.20)](./Program2/) — Demonstrate the use of a `union` and display its members safely one at a time.

## Compile & Run
```powershell
gcc -Wall -Wextra -std=c11 Program1/main.c -o Program1/program.exe
.\Program1\program.exe

gcc -Wall -Wextra -std=c11 Program2/main.c -o Program2/program.exe
.\Program2\program.exe
```
