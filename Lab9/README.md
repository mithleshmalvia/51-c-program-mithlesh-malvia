# Lab 9: Pointers and Structures

## Objectives
- Manipulate variable values indirectly through pointer dereferencing.
- Group heterogeneous student attributes using a `struct`.

## Programs
1. [Program 1 (Q.17)](./Program1/) — Swap two numbers using pointers and display values before and after swapping.
2. [Program 2 (Q.18)](./Program2/) — Store and display a student's name, roll number, and marks using a structure.

## Compile & Run
```powershell
gcc -Wall -Wextra -std=c11 Program1/main.c -o Program1/program.exe
.\Program1\program.exe

gcc -Wall -Wextra -std=c11 Program2/main.c -o Program2/program.exe
.\Program2\program.exe
```
