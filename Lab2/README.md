# Lab 2: Switch-Case and Loop Skipping (`continue`)

## Objectives
- Implement multi-way branching using `switch-case` statements with error handling for division by zero.
- Control loop iteration flow by skipping specific iterations with the `continue` statement.

## Programs
1. [Program 1 (Q.3)](./Program1/) — Simple calculator using `switch-case` (`+`, `-`, `*`, `/`).
2. [Program 2 (Q.4)](./Program2/) — Print numbers from 1 to 50 while skipping multiples of 5 using `continue`.

## Compile & Run
```powershell
gcc -Wall -Wextra -std=c11 Program1/main.c -o Program1/program.exe
.\Program1\program.exe

gcc -Wall -Wextra -std=c11 Program2/main.c -o Program2/program.exe
.\Program2\program.exe
```
