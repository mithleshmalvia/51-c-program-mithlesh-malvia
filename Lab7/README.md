# Lab 7: Functions, Call by Value, and Call by Reference

## Objectives
- Write modular C functions that accept arguments and return a computed value.
- Understand the difference between call by value and pointer-based call by reference in C.

## Programs
1. [Program 1 (Q.13)](./Program1/) — Calculate the sum of two numbers using a function with arguments and a return value.
2. [Program 2 (Q.14)](./Program2/) — Demonstrate call by value and call by reference (via pointers) by swapping two numbers.

## Compile & Run
```powershell
gcc -Wall -Wextra -std=c11 Program1/main.c -o Program1/program.exe
.\Program1\program.exe

gcc -Wall -Wextra -std=c11 Program2/main.c -o Program2/program.exe
.\Program2\program.exe
```
