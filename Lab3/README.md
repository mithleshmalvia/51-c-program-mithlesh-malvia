# Lab 3: Loop Termination (`break`) and 1D Arrays

## Objectives
- Terminate loop execution early upon meeting a condition using the `break` statement.
- Store and traverse elements in a one-dimensional (1D) array to find minimum and maximum values.

## Programs
1. [Program 1 (Q.5)](./Program1/) — Print numbers from 1 to 100 and stop when the number reaches 50 using `break`.
2. [Program 2 (Q.6)](./Program2/) — Find the largest and smallest elements in a one-dimensional array.

## Compile & Run
```powershell
gcc -Wall -Wextra -std=c11 Program1/main.c -o Program1/program.exe
.\Program1\program.exe

gcc -Wall -Wextra -std=c11 Program2/main.c -o Program2/program.exe
.\Program2\program.exe
```
