# Lab 5: Pattern Printing Using Nested Loops

## Objectives
- Practice row-and-column pattern generation using nested `for` loops.
- Coordinate leading spaces alongside ascending and descending number sequences.

## Programs
1. [Program 1 (Q.9)](./Program1/) — Print the 5-row Number Triangle using nested loops.
2. [Program 2 (Q.10)](./Program2/) — Print the 5-row Centered Number Pyramid using nested loops.

## Compile & Run
```powershell
gcc -Wall -Wextra -std=c11 Program1/main.c -o Program1/program.exe
.\Program1\program.exe

gcc -Wall -Wextra -std=c11 Program2/main.c -o Program2/program.exe
.\Program2\program.exe
```
